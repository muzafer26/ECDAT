# Raw Benchmark Outputs

**Path:** `product/benchmark/tools/raw_outputs/`

This directory archives untouched raw outputs (JSON, SARIF, CBOM CycloneDX, XML, or CLI stdout) generated by external discovery tools when executed against test fixtures.

## Rules
1. Never edit raw outputs manually.
2. Store each run under `<tool_id>/<timestamp_or_run_id>/`.
3. Preserve raw artifacts as benchmark audit evidence.
